# Code of Conduct

## Our standard

Supabase User MCP is committed to a respectful, technically rigorous, and welcoming
community. We value disagreement that improves the design and reject behavior that makes
participation unsafe or demeaning.

Expected behavior includes:

- critiquing ideas and evidence rather than people;
- stating uncertainty and correcting mistakes openly;
- welcoming questions and different experience levels;
- respecting privacy, credentials, and embargoed security information;
- giving credit for ideas and work; and
- accepting maintainer decisions without harassment, while preserving the right to fork
  under the license.

Unacceptable behavior includes harassment, threats, discriminatory language, sexualized
attention, doxxing, credential exposure, deliberate disruption, or publishing private
security details without coordination.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, community
spaces, and public interactions where someone represents the project.

## Enforcement

Report conduct concerns privately through the maintainer's
[GitHub profile](https://github.com/jryski). For security vulnerabilities, use the process
in [SECURITY.md](SECURITY.md).

Maintainers may edit or remove content and may warn, temporarily restrict, or permanently
ban participants whose behavior is inconsistent with this code. Reports will be handled
as confidentially as reasonably possible. Retaliation against a reporter is prohibited.
